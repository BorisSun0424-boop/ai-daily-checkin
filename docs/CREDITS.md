# AI 积分活动与时效对照表

> 数据核验：**2026-10-31**。规则变动频繁，**以各平台官方活动页为准**。
> 这张表回答两件事：**每天能领多少**、**领了能留多久**。后者对实际价值影响更大。

---

| **Trae Work** | 客户端 | **200** 积分 | 注册 4000、邀请 500/人、每月 500 通用 | 官方称"不同渠道有效期不同"，未统一明示 | — |

## 二、按"能留多久"分档（这个才是重点）

| 档位 | 平台 | 意味着什么 |
| --- | --- | --- |
| **当天必须用** | 扣子（1 天）、Qoder（10:00 窗口） | 不当天花就等于没领 |
| **30 天内用** | MiniMax Code | 可以攒，但别囤太久 |
| **月底 / 活动截止清零** | WorkBuddy 付费积分、WorkBuddy 签到活动（2026-12-31） | 到期未用直接没收 |
| **未明示（按活动页）** | Trae、豆包工作、智谱登录积分 | 建议定期看余额页 |

---

## 三、使用顺序建议

1. **先花当天失效的**：扣子 1500（1 天）、Qoder 100（次日 10 点前）
2. **再花 30 天的**：MiniMax 400
3. **最后花月度 / 长期的**：WorkBuddy、Trae、豆包工作

反着来是纯亏——很多人把"当天要过期的 1500"放着没用，去花月底才清零的积分。

## 四、有活动但不是"签到型"（了解即可）

| 名称 | 情况 |
| --- | --- |
| 海螺 AI（MiniMax） | 注册赠积分，未见每日签到 |
| 腾讯元宝 / 豆包 App | 福利中心签到，在 App 内，额度较小 |
| 火山方舟 / 阿里云百炼等 | 新用户 token 礼包，非签到 |
| 智谱体验卡 / Coding Plan | 活动型一次性发放 + 短有效期 |

## 五、没有签到机制的（已核实）

- **Kimi**：网页端无签到（JS 全量检索 + 接口探测双证伪）
- **文心**：网页端无签到（产品已迁移到 wenxin.baidu.com）
- **通义万相**：接口存活但产品已并入千问，签到入口可能失效
- **豆包 / 元宝网页端**：签到在客户端或 App 内
